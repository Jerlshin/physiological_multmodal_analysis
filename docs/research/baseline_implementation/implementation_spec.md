# Implementation specification (IS) — operational clarifications of the frozen protocol

Version 1.1, 2026-10-05. Version 1.0 held IS-001…IS-027; IS-028 and IS-029 were added during freeze finalization. **Every entry was written before any access to real quiz outcomes.** No physiology–outcome association has been computed by anyone in this project.

[protocol.md](../experimental_design/protocol.md) remains the analysis contract. This document fixes only what the protocol leaves operationally open, so that a second implementer would produce identical numbers. Each entry names the protocol clause it implements.

- None of these clarifications changes the question, population, outcome, feature dictionary, model families, metrics or inference procedures.
- Entries marked **(design-simulation alignment)** resolve an ambiguity in favour of the procedure whose operating characteristics the design phase simulated.

The configuration that carries the numbers is [configs/g01r_protocol_v1.toml](../../../configs/g01r_protocol_v1.toml). Its SHA-256 is recorded in every run and in the freeze manifest.

## EEG

| ID | Protocol clause | Specification | Why |
|---|---|---|---|
| IS-003 | §6 valid EEG ("not exactly zero") | The released BDFs store 16-bit codes with a symmetric physical range, so 0 µV is not representable. Per channel, a sample is "exactly zero" when its digital code is one of the two codes bracketing 0 µV: the floor and ceiling of the exact zero crossing, i.e. −1 and 0 for this release. Chance occurrences (≈10⁻⁴ per sample) are also treated as invalid, by the literal rule. | The audit counted 0 exact physical zeros for exactly this reason. The authors' zeroed artifact runs (up to 195 samples, observed in the QC survey) appear as these codes |
| IS-004 | §6 RF1/RF2 | **Welch.** Fixed grid of 4-s Hann windows (512 samples, step 256) starting at sample 0. A window enters a channel's PSD only if that channel has no zeroed sample in it. PSD = mean of the used windows' periodograms, with `scipy.signal.welch` density scaling (equal to `welch` when all windows are valid; unit-tested).<br>**Band power.** Sum of bins with lo ≤ f ≤ hi, times Δf. The denominator excludes bins with 14.5 ≤ f ≤ 17.5 Hz.<br>**Valid data.** A channel's valid data are the samples its used windows cover. Channels with < 60 s are dropped. The feature is the median over the remaining named channels, and is missing if none remain. | Literal "segments without zeroed samples" with a deterministic grid |
| IS-007 | §6 SYN1 | **CorrCA data.** Each channel is centred over its valid samples; invalid channel-samples are set to 0 (the authors' covariance convention, `preprocessEEGdata.m`).<br>**Covariances.** R_w = Σ X̃ᵀX̃ over fitting cells. R_b = Σ over experiment × video units of (Σ_{i≠j} X̃ᵢᵀX̃ⱼ)/(N_u − 1).<br>**Shrinkage and filters.** R_w ← 0.5·R_w + 0.5·(tr R_w/64)·I. Generalized eigenproblem; the filters are the top-3 eigenvectors.<br>**Sufficient statistics.** Pairwise cross-products are precomputed once per unit as exact sufficient statistics (memory-mapped). | Pooled CorrCA over units with different viewer counts; exact for any fitting subset |
| IS-008 | §6 SYN1 "samples valid in both" | **Component validity.** A projected sample is valid only if all 64 channels are valid there.<br>**Reference mean.** The mean, at each sample, over the reference people valid at that sample (at least one).<br>**SYN1.** Pearson r is computed on samples valid for both target and reference. SYN1 = Σ of the three component r's, and is missing if the jointly valid samples fall below 60 s.<br>**Other synchrony features.** SYN2, SYN3 and SYN-P use the same reference-mean rule; SYN3 = mean(r_x, r_y). | A projection is undefined where any channel is zero-filled |
| IS-021 | §13.4 raw route | **EEG, gaze and pupil** come from the raw exports exactly as in [measurement_provenance.md](../experimental_design/measurement_provenance.md), in this order: zero-phase 0.5 Hz order-5 high-pass, then 59–61 Hz order-5 band-stop, then CAR, then least-squares regression of the identically filtered raw EOG, then 4×IQR missing with ±5 samples (±40 ms) dilation.<br>**ECG timing features and Q** are route-independent, so M2 is identical across routes. | Only physiology changes between routes |

## ECG and eye

| ID | Protocol clause | Specification |
|---|---|---|
| IS-005 | §6 RF3/RF4/SYN2 | **Peaks and RR.** R-peaks are kept within [0, end]; RR intervals are the consecutive differences, and an RR is valid in [0.3, 2.0] s.<br>**60-s rule.** RF3 and RF4 use the sum of valid RR as the valid duration.<br>**RMSSD.** Pairs are consecutive RR, both valid, with \|ΔRR\| < 0.2·RR_prev.<br>**HR series.** 60/RR is placed at the closing beat of each valid RR and linearly interpolated on a 2-Hz grid from t = 0; it is NaN outside the first and last valid beat (no extrapolation). |
| IS-006 | §6 valid gaze/pupil | **Gaze.** As in the protocol.<br>**Pupil.** Valid when outside the pupil correction intervals, finite, > 0, and the gaze is on screen (finite and in bounds) whenever a gaze file exists.<br>**Saccades.** A saccade counts when its onset lies inside [0, end) and outside every gaze correction interval, in continuous time (start ≤ t < end is excluded).<br>**Rate and z-score.** Valid gaze minutes = valid gaze samples/128/60. The pupil z-score uses that recording's valid samples. |

## Splits, references, pipeline

| ID | Protocol clause | Specification | Why |
|---|---|---|---|
| IS-009 | §11, M06 §3 "seeds" | **Seeds.** Every random stream (outer and inner folds, half splits, permutations, bootstraps, synthetic data) comes from `SeedSequence(20261004, labels)` and is addressed by labels such as set name, regime, repetition and fold.<br>**Shared folds.** All analyses on the same set share folds, inner folds and permutations, so comparisons are paired.<br>**Determinism.** EEG projections are float64 and computed per plan, so results are bit-identical whatever the batching or parallelism (verified). | Reproducibility and pairing |
| IS-023 | — | Base seed **20261004**, frozen now, before outcome access | — |
| IS-010 | M06 §2 regime C | **Half split.** Each repetition splits the people of each experiment at random into two halves, at person level, with the same halves for all videos.<br>**Test reference.** The other half's viewers of the held-out video in the same experiment, from any fold.<br>**Training reference.** The other half's viewers among training people only.<br>**CorrCA.** Fit on training cells only, which never include the held-out video. | Leakage rule 4: a test person's other cells are never used |
| IS-011 | §6 missing features | **Physiological blocks.** One block missing-indicator per block (RF_EEG, RF_ECG, RF_GAZE, RF_PUPIL, SYN_EEG, SYN_ECG, SYN_GAZE, SYN_PUPIL), equal to 1 if any feature of the block is missing. It is always included; a constant column is inert under standardized ridge.<br>**C.** Sex-unknown and digit-span-missing indicators.<br>**Q.** Gaze-missing, EEG-missing and pupil file-absence indicators.<br>**GPA sensitivity.** GPA plus a missing indicator. | Data-independent design columns |
| IS-012 | §8 steps 1–2, regimes B/C | **(design-simulation alignment)** For unseen content, the prediction offset is the training experiment mean. The residual target of training cells is y minus the training experiment × video mean of the training content. | Identical to `precision_simulation.cv_setting_B`, whose properties underlie the descriptive B/C claims. It removes training-video difficulty from the target |
| IS-013 | §8 step 6 | **Inner fold.** Assigned per training person (random permutation, modulo 5).<br>**Fixed features.** Features, including SYN with outer-training references, stay fixed within the outer split.<br>**Standardization.** Recomputed on inner-training rows.<br>**Imputation.** Values come from the outer training split, because step 5 precedes step 6. | Matches the simulation |
| IS-014 | §11 H1 with split-dependent SYN | **Paired splits.** For each paired split (the first 10 of the 50 regime-A repetitions × 10 folds), the full model's imputed design over all cells is used.<br>**Residualization.** The tested block is regressed by full-data OLS (no outcomes) on experiment × video dummies plus the nuisance columns (C, Q and earlier blocks).<br>**Permutation.** One person-block permutation per draw is applied to every split; base-model losses are unchanged.<br>**Statistic and p-value.** The statistic is the person-balanced loss difference over the 10 repetitions; p = (1 + #{null ≥ obs})/(B + 1). | The protocol procedure with per-split features; the identity permutation reproduces the observed fit exactly (unit-tested) |
| IS-025 | §11 futility | The corrected resampled-t uses all R·K = 500 fold-level person-mean differences of the R = 50 point estimate, with var·(1/J + 1/(K−1)) and z = 3.0, divided by the person-balanced base MSE. | Production configuration, validated in V1 |
| IS-015 | §11 B/C | Each two-way bootstrap replicate computes skill = 1 − Σ w·l_full / Σ w·l_base with w = W_person·W_video / n_cells(person), i.e. the person-balanced within-content skill. Person weights are stratified by experiment. The interval is a percentile 90% interval. | Bootstrap statistic matches the point estimate |
| IS-016 | §11, §13.7, §14 state | Three nested-CV losses come from the same fits:<br>• **person-balanced**, for H1;<br>• **cell-weighted** (H3.7): per-person sums × n_people/n_cells;<br>• **state**: double-centred losses among people with ≥ 2 cells, same scaling.<br>The person stays the resampling unit throughout. | Bates et al. assume independent units |
| IS-017 | M06 §5 explanatory | **Model.** REML with person and experiment × video random intercepts and profiled residual variance.<br>**Fixed effects.** Intercept, an E4 indicator and the standardized non-constant M5 inputs, with SYN from full-cohort leave-self-out references.<br>**Inference and labelling.** Wald SEs. Labelled explanatory. | — |
| IS-018 | M06 §5 shortcut (ii) | A one-vs-rest ridge classifier predicts the experiment × video unit from RF + SYN on the frozen regime-A folds (first 10 repetitions), with an inner person-grouped penalty. Its accuracy is reported against the majority rate. | — |
| IS-019 | §14 transport | **Fit.** One fit on the whole source cohort, predicting the target cohort (the cohorts are disjoint).<br>**Offsets.** The source cohort's mean for the same canonical video; the recalibrated variant uses target video means and is labelled as using target labels.<br>**Interval.** Stratified person bootstrap of target learners, conditional on the fitted model. | — |
| IS-020 | §14 CAS | **Folds.** Over CAS people.<br>**Models.** M2 is trained on all CAS training cells, with Q indicators. M5 is trained on PAS-core training cells, with PAS-core training references.<br>**Policy.** M5 for PAS-core cells, M2 otherwise.<br>**Reporting.** Descriptive point estimates for all cells, for core cells and for non-core cells. | — |
| IS-022 | §14 E1 | C = age and sex. Q = gaze correction, gaze missing, pupil correction and pupil absence. M5_E1 = M2 + gaze RF + gaze SYN. | No EEG/ECG/ASRS/digit span in E1 |
| IS-026 | §11 H1 | The permutation statistic uses repetitions 1–10 of the 50 point-estimate repetitions, so its folds are paired with the point estimate. | — |
| IS-027 | readiness condition 2 | The detection procedure is read from `validation/validation_verdict.json`: the permutation test, unless the production false detection in V1 or V2 exceeds 0.07, in which case the declared person-bootstrap fallback is used. | Fallback declared before outcomes |

## Reporting and run integrity (added in freeze finalization)

| ID | Protocol clause | Specification | Why |
|---|---|---|---|
| IS-028 | §13 vs estimand §5 (H3) | **What H3 reports.** Each H3 analysis reports the person-balanced point estimate Ŝ (R = 50) of M5 over M2 and its nested-CV 90% interval (H3.7: the cell-weighted versions from the H1_H2 fits). No permutation p-value and no futility bound are computed, so the H1 decision category is not re-evaluated.<br>**How robustness is read.** For each analysis we state (i) whether Ŝ has the same sign as the primary Ŝ and (ii) whether Ŝ lies on the same side of δ = 0.05 as the primary Ŝ. Agreement on both is described as "robust", any disagreement as "sensitive to <analysis>". H3 introduces no additional confirmatory test and does not revise the H1 conclusion.<br>**Status.** Final interpretation, confirmed by the user on 2026-10-05 before any real-outcome access (BID-026). The estimand §5 text carries a matching dated clarification. | The estimand's v1.0 wording "keeps its sign and its decision category" presupposes a test that protocol §13 excludes ("no new tests"). The protocol is the analysis contract, so only the estimate-based parts of the category are read |
| IS-029 | §8 step 3; §11 | **Synchrony caches.** Synchrony features and CorrCA sufficient statistics are deterministic, outcome-free functions of the bound signal caches and the frozen code. Confirmatory runs may reuse entries of `data/derived/g01r/syn_cache` and `corrca_stats` and add new ones.<br>**Binding.** Every entry present at the freeze is listed with its SHA-256 in `analysis_freeze/derived_cache_index.json`, which the manifest binds. Verification is append-only: a frozen entry that changed or disappeared blocks outcome access; entries added later are allowed.<br>**Consistency.** The frozen code reproduces the cached entries bit for bit ([cache_consistency.json](evidence/validation/cache_consistency.json)). | The cache was largely written before the last edit of `features/synchrony.py`. Reuse is a compute saving only and must not be a source of differences |

## Explicitly not changed

- Sets, QC thresholds, outcome, δ and 2δ, the feature list, the λ grid, the model list, R, K, B, the nested-CV repetitions, z, Holm and the decision table are all exactly as in the protocol.
- No feature, threshold, penalty grid or model was chosen by looking at outcomes; none were available.
