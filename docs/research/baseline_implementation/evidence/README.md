# Evidence — Baseline Implementation & Analysis Freeze (2026-10-05)

Every file here is regenerated by `PYTHONPATH=src .venv/bin/python -m g01r <command>`, run from the repository root.

**No file contains an outcome value or participant-level physiological values.**

- **Population** files hold keys and set-membership flags only.
- **Feature QC** holds aggregates only.
- **Validation** files are simulated or synthetic-outcome replicates.

| Path | Command | Content |
|---|---|---|
| `population/analysis_sets.csv` | `population` | Cell keys and the membership flags of the 10 frozen and 3 derived sets |
| `population/case_flow.csv` | `population` | Stage-wise case flow (identical to the design phase) |
| `population/population_summary.json` | `population` | Counts per set and per experiment, and the verification against the frozen manifest |
| `feature_qc/feature_qc.json` | `feature-qc` | Per set and route: aggregate distributions, missingness, Spearman correlations among physiology and quality, route agreement, REVISE trigger |
| `feature_qc/feature_summary.csv` | `feature-qc` | The same distributions in tabular form |
| `validation/v1_replicates_{null,truth_at_2delta}.csv` | `validate-v1` | Production re-simulation, 300 datasets per scenario: estimate, truth, permutation p, futility bound, nested-CV bounds, fallback |
| `validation/v1_summary.csv` | `validate-v1` | Operating characteristics |
| `validation/v1_bit_identity_check.csv` | (script in the validation report) | Four V1 datasets re-run on the final code |
| `validation/v2_replicates_{pure_null,nuisance_null,planted_rf_signal}.csv` | `validate-v2` | Real features with synthetic outcomes |
| `validation/v2_summary.csv` | `validate-v2` | Detection and estimate summaries |
| `validation/validation_verdict.json` | `validation-verdict` | Protocol §17.3 checks and the fixed detection procedure (read by the confirmatory runner) |
| `validation/cache_consistency.json` | `python docs/research/baseline_implementation/evidence/validation/cache_consistency.py` | Freeze finalization: bit-for-bit recomputation of the reused CorrCA and synchrony cache entries with the frozen code |

The run records of these commands, with configuration hash, git state, code hash, environment and data identity, are in `results/runs/` and `results/mlflow/` (git-ignored).
