# Dataset and literature bibliography

Evidence cutoff: **2026-10-01**. Sources are grouped by dataset; exact DOI/repository links support the corresponding notes. Publisher year, online year, release year and mirror date are distinguished in those notes. A listed source may establish access or methodology without proving that every file was downloaded or every result replicated.

The search used original papers, official repositories/project pages and author-controlled code; search-engine snippets and third-party reviews were discovery leads. Inaccessible full text and unresolved reuse are marked in the notes. Dataset descriptors and their preprints are not counted twice. Counts below are lower bounds, not citation totals.

## Scientific occupancy: verified examples

| Resource | Verified work types / conservative lower bound | What is already occupied |
|---|---|---|
| BBBD | 3 antecedent empirical papers + 1 descriptor | Eye synchrony→quiz; heart synchrony/attention/recall; brain–heart–eye synchrony/covariation |
| ds003838 | Descriptor + ≥3 empirical journal analyses + 1 thesis + 1 software release | EEG/pupil overload; PPG amplitude and workload; cardiac aperiodic activity; pupil–ECG fusion; heartbeat-locked template construction |
| DREAMT | ≥2 peer-reviewed methods works | Wearable sleep staging, temporal/mixed-effects modelling, ECG/PPG IBI transfer |
| IMPROVE | Descriptor + ≥1 related conference analysis | Phone distraction from biometric/head/gaze measures; exact overlapping subset needs audit |
| SENSE-42 | Descriptor + 1 CHI extended-abstract paper identified | Sleepiness fluctuation prediction; full methods unavailable in this review |
| COG-BCI | Descriptor + ≥2 confirmed journal uses | Load classification, preprocessing/source localization; other transfer leads not counted without identity audit |
| SEED-VII | Original + ≥2 reuse works | Intensity-aware emotion, adaptive fusion, cross-dataset EEG recognition and EEG–eye contrastive alignment |
| DEAP / AMIGOS / WESAD | Original + ≥2 illustrative reuse works each | Fusion, representation learning, cross-dataset/person evaluation, authentication or user bias; actual literature much larger |
| K-EmoCon | Descriptor + ≥1 independent 2026 empirical reuse | HRV synchrony, speaker–listener phases and self/partner emotion associations |
| Other recent resources | Usually descriptor/baseline verified; additional independent reuse not established | Read individual notes: low verified count does not mean unused or novel |
