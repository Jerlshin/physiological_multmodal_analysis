## Two technical-validation statistic issues

**VERIFIED FACT (INF-019).** In [figures-paper.ipynb](https://github.com/madjens/bbbd-dataset/blob/5109afa0fd70c407b869108106f5808c6b0cc33c/figures-reproduction/figures-paper.ipynb), function `hrv_per_subject` selects `*rpeak_timestamps.tsv.gz`, takes the first column and calculates `sqrt(mean(diff(column)**2))`. If that column contains R-peak times as its filename and descriptor indicate, `diff(column)` is RR intervals, and the statistic is the root mean square of RR intervals. Standard successive-interval RMSSD would require differences of those RR intervals, i.e. a second difference of peak times. This mathematical mismatch is directly identifiable without running a model. The actual input column and file version must be inspected before attributing the discrepancy to the published figure. The notebook also uses a default header parser for these files, making header-format agreement relevant. **Status: verified code formula; published numerical impact OPEN.**

**VERIFIED FACT (INF-020).** Function `pupil_iqr_per_subject` computes each pupil file's 75th minus 25th percentile and averages by participant/session. This supports the descriptor Figure 7 caption's IQR interpretation, not automatically the narrative statement about mean pupil size/dilation. Do not quote the figure as evidence of a tonic mean change until the executed analysis is identified.

## Reproducibility boundaries

The repository supplies MATLAB preprocessing/reformatting, EEGLAB-dependent BDF export, Python/MATLAB downloads and a figure notebook. Its config points to upstream MATLAB arrays and helper routines; option values, native files, manual annotations and package versions are not all bundled into a proven end-to-end environment. No standalone LICENSE file was found in the inspected tree. The repository commit predates the Sept. 25 release correction, even though some reference tables reflect updated counts; never presume byte identity to the ZIPs.

The [metadata audit script](audit_repository_metadata.py) performs only schema/count/hash checks on these reference TSVs. It does not inspect responses, infer health conditions, train a model or verify scientific outcomes. Re-run on the pinned checkout, then separately compare actual release files. The stored aggregate output provides exact filenames, SHA-256s, headers, row counts and nonmissing counts.
