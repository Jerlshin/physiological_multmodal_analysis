**Consequence:** the ECG filter discrepancy is empirically narrowed, and exported scale/representation semantics are clearer. Exact EEG and eye provenance cannot be recovered by fitting a plausible spectrum. An alternative processing route would need a documented source transformation, masks/options and validation; the available aligned raw exports do not reconstruct discarded native samples or annotations. OQ-06 therefore stays **BLOCKING / EMPIRICALLY NARROWED**, rather than being declared resolved from defaults.

## Experiment 2: content canonicalization is distinct from response canonicalization

**EMPIRICALLY VERIFIED:** Exp.1 and Exp.2 release JSONs contain exactly the same **106 question texts and option orders**: 47 domain and 59 memory items. Exp.1 numbers questions within stimulus; Exp.2 numbers globally within question type. [Explicit content map](evidence/gate_closure_quiz_content_map.csv). Both releases put the correct response at canonical option 1. A uniform key is therefore structurally reasonable; it is not proof of a key error.

The historical workbook matches all 59 memory question texts after whitespace normalization. It matches 58 option lists after whitespace normalization; the boys/girls ratio question's original numeric options were serialized as Excel durations, so that row cannot supply an exact textual option mapping. Category labels are historical workbook metadata, not released native item timestamps. These content checks do not establish that a participant's recorded position was transformed through the presented random permutation.

| Experiment 2 source | Domain mean, per video | Memory mean, per video | Available unit/identity |
| --- | --- | --- | --- |
| Released v1.1 keyed items | 0.255293 | 0.257087 | 31 released people × 5 videos; responses and supplied keys present |
| P01 OSF `Npoints_stim_pre/post` | 0.501790 | 0.545308 | 31 × 5 aggregate percentages; participant keys/permutations absent |

This is a direct, original-source **non-equivalence**, not merely an unusual near-chance distribution. Both sets have 155 cells with the expected denominators; their aggregate sums differ, so permuting participant rows or video columns cannot make them the same values. The companion historical demographics file has the same 31 participant-number keys as the release; keyed age/sex match for all 31, study time matches for 28 with three shared missing values, and GPA matches for 29 with two shared missing values. This strongly supports cohort correspondence. A historical 31 × 5 stimulus-order matrix contains valid 1–5 permutations. The score/order matrices themselves carry no participant keys, and the inspected analysis code does not supply the originating response-to-option transformation. **OPEN:** original response-option transformation, score-matrix row binding and which scoring/export step explains the discrepancy. Historical aggregates cannot safely replace release labels by array position. Historical correctness is not assumed infallible, and the comparison does not establish a defect in an original publication.

The current [official correction log](https://bbbd.pythonanywhere.com/changelog) describes quiz fixes for experiments 4–5; it does not certify an Exp.2 answer-order correction. The public quiz exporter copies reference TSV/JSON assets; it does not reconstruct randomized-option responses. Retrieved P01 questionnaire metadata contains traits/feedback, not those answer permutations. No available inspected source supplies the missing mapping.

**Decision / OUR INFERENCE:** Exp.2 scores are not sufficiently certified for behavioral pooling, ranking incidental versus intentional learning, learning-gain computation, or physiology–quiz associations. Preserve them for encoding diagnostics; keep its signals and narrowly named condition contrasts available within the remaining provenance limits. No majority-vote key, score-maximizing permutation, participant reassignment or historical aggregate substitution is used. This closes the immediate safety decision while leaving causal provenance open.
